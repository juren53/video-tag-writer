First release of **Video Tag Writer**: a desktop viewer/editor for descriptive metadata in **MP4, MPG and MPEG** video files. It follows the design of [Audio Tag Writer](https://github.com/juren53/audio-tag-writer).

### Highlights
- **MP4 / M4V**: metadata is written inside the file, as iTunes-style tags (visible in players, Windows Explorer and ffprobe) plus XMP (Dublin Core and other archival schemas).
- **MPG / MPEG**: these formats can't hold descriptive tags, so metadata goes in a `<name>.xmp` sidecar beside the video. The video file is never modified.
- **Modes**: Archival Video (HSTL profile), General and TV Episode, with auto-detect on load and Manage Modes for custom field sets.
- **Video panel**: cover art or a poster frame, plus technical info (container, duration, codecs, resolution, frame rate, scan type, audio).
- Directory navigation (↑ ↓), View All Tags, JSON export/import, rename (moves the sidecar too), themes and zoom.

### Notes
- Metadata engine: ExifTool, chosen over Mutagen and FFmpeg after a probe test. See [notes/TOOL_COMPARISON_mutagen-vs-ffmpeg-vs-exiftool-video.md](https://github.com/juren53/video-tag-writer/blob/master/notes/TOOL_COMPARISON_mutagen-vs-ffmpeg-vs-exiftool-video.md).
- Keep each `.xmp` sidecar with its MPG/MPEG file when copying or archiving.
